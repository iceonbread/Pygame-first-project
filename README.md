# Pygame-first-project

A simple 2D platformer game built with Pygame. Navigate through platforms, avoid enemies, and reach the goal!

## Features

- Player movement with arrow keys or A/D keys
- Jump mechanic with Space bar
- Multiple platforms to navigate
- Moving enemies to avoid
- Goal to reach for victory
- Game over and win conditions
- Restart functionality

## Requirements

- Python 3.7 or higher
- Pygame 2.0.0 or higher

## Installation

1. Clone this repository:
```bash
git clone https://github.com/iceonbread/Pygame-first-project.git
cd Pygame-first-project
```

2. Install the required dependencies:
```bash
pip install -r requirements.txt
```

## How to Play

Run the game with:
```bash
python game.py
```

### Controls

- **Arrow Keys** or **A/D**: Move left and right
- **Space**: Jump
- **R**: Restart game (when game over or won)

### Objective

- Navigate through the platforms
- Avoid the red enemies
- Reach the yellow goal at the top
- Don't fall off the screen!

## Game Elements

- **Blue Rectangle**: Your player character
- **Green Platforms**: Surfaces you can stand on
- **Red Squares**: Moving enemies (avoid them!)
- **Yellow Square**: Goal (reach it to win!)
